# مذاكرجي قانون PRO v3

نسخة نهائية موجهة للاستخدام الشخصي Offline.

## ما الذي يفعله التطبيق؟
1. يستقبل ملفات محاضرات طويلة من الهاتف.
2. يحول الصوت إلى نص عربي محليًا باستخدام Sherpa-ONNX/Whisper.
3. يسمح باختيار موديل GGUF محلي.
4. يشغل LLM محليًا عبر llama.cpp داخل التطبيق.
5. يوفر:
   - ملخص
   - شرح للمبتدئ
   - تعريفات وقواعد واستثناءات
   - أسئلة مقالية صعبة
   - MCQ صعب
   - حالات عملية
   - خريطة ذهنية
   - بطاقات مراجعة
   - اختبار ذاتي
   - مشاركة النتائج

## ملاحظات واقعية
- لا توجد حسابات أو API.
- بعد تجهيز موديلات الجهاز يمكن استخدام التطبيق بدون إنترنت.
- موديل Whisper يتم تنزيله في GitHub Actions ولا يوضع في Git history.
- موديل GGUF لا يتم تضمينه في APK؛ تختار ملف GGUF من الهاتف مرة واحدة.
- أداء الـLLM يعتمد على RAM/CPU في الهاتف. الموديلات الأصغر 1B–3B أكثر واقعية للأجهزة المتوسطة.
- لا تستخدم التطبيق كبديل عن مصدر قانوني أو كتاب/محاضرة رسمية؛ الذكاء المحلي قد يخطئ، لذلك راجع النص الأصلي.

## البناء
ارفع المشروع إلى GitHub ثم:
Actions -> Build LawOfflineAI PRO -> Run workflow
